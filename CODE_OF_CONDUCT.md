# Community expectations

OmniDev Workspace welcomes constructive discussion and contributions from people with different experience, languages and backgrounds.

Be respectful, discuss the code and evidence, and explain disagreements without targeting people. Clear criticism of a design or implementation is welcome. Harassment, threats, doxxing, discriminatory abuse and posting private credentials/content are not acceptable.

Keep reports relevant and reproducible. Do not test on another person's device, account or data without permission. Do not publish private vulnerability details through ordinary issues; use [SECURITY.md](SECURITY.md).

The [maintainer](https://github.com/obieda-hussien) moderates repository discussions and can edit/remove content or limit participation when necessary. If an available private profile contact exists, use it for a sensitive conduct report; otherwise request a private contact without identifying affected people in a public issue.

This file states the project's own community expectations. It does not claim a certification, a fixed enforcement timeline or adoption of a separate third-party code-of-conduct framework.
